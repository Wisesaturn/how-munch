# 커밋 컨벤션

## 형식

```
type/#{이슈번호}: 한 줄 요약

- 작업 내용 A
- 작업 내용 B
```

## Type

| Type       | 사용 시점                     |
| ---------- | ----------------------------- |
| `feat`     | 새 기능                       |
| `fix`      | 버그 수정                     |
| `refactor` | 동작 변화 없는 구조 개선      |
| `chore`    | 빌드, 설정, 패키지 유지보수   |
| `docs`     | 문서, 주석                    |
| `style`    | 포매팅, 린트 (기능 변화 없음) |

## 작성 규칙

- 제목은 한국어로, 마침표 없이 간결하게
- 본문은 `- 내용` 불릿 형식으로 작성
- **Co-Authored-By 추가하지 않음**
- 커밋 본문 작성 시 `\n` 문자열을 직접 입력하지 말고 실제 줄바꿈 사용

## 예시

```
feat/#{이슈번호}: 냉장고 아이템 유통기한 알림 기능 추가

- 유통기한 D-3 이하 아이템에 뱃지 표시
- 소진된 재고는 알림 대상에서 제외
```

```
fix/#{이슈번호}: 식단 등록 시 재고 차감이 두 번 발생하는 버그 수정

- upsert_meal_with_usage RPC 호출 조건 누락 수정
```

```
refactor/#{이슈번호}: queryKey를 entities로 통합

- fridgeItemKeys, mealKeys 등 entities 레이어로 이동
- 기존 features/api/queryKey.ts 파일 제거
```
